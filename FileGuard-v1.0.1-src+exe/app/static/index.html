config.yaml

配置文件为 YAML 格式，每一项上方的 # 注释说明了用途、取值范围与默认值， 可以放心保留或删除（程序不会读取注释）。
保存时程序会按内置默认结构重新渲染全文，注释会自动补回， 升级新增的配置项也会自动出现。
注意：值里含「冒号+空格」「#」时要用英文引号包起来； 修改监控目录、回收站路径、日志目录、端口等需点击顶部「停止服务 → 启动服务」后生效； Web 端口变更后请使用新端口重新打开本页面。
